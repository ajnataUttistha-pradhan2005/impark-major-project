# Frontend/backend contract

The browser uses the Next.js same-origin proxy to the FastAPI `/api/v1` single-workspace API. Discovery, clarification, conversation, uploaded images, durable runs, replayable SSE, citations, cancellation and recovery are described in the [current API/frontend guide](docs/api-and-frontend/README.md). Consult the [frontend component guide](frontend/README.md) and the running `/openapi.json` for exact current types. The former response-only LLM contract described in older versions of this file is no longer the active DeepAgents answer path.
