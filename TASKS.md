# Current roadmap and open validation work

The previous phase-by-phase deterministic-harness task table described an architecture that has been removed. The current implemented system is mapped in [architecture](docs/architecture/README.md), [file map](docs/repository-map/README.md), [API](docs/api-and-frontend/README.md), and [setup](docs/setup-and-operations/README.md). Remaining work should be derived from verified gaps rather than the retired roadmap. Known limits are listed in [testing and limitations](docs/testing-and-limitations/README.md): independent scientific fact-checking of pretrained explanations, broad image validation, multi-worker scaling, and systematic live-model latency/quality evaluation remain unproven. Do not describe these as completed without new evidence.
